# 产品需求分析


## 产品定义

运行于桌面端的，带有live2D效果的陪伴机器人。

为用户带来快乐，以及可以处理简单的任务（e.g. 你去帮我把桌面的图片转成jpg格式）。


## 功能性需求

### 接入QQ，微信

支持QQ，微信接入，用户可以在QQ，微信上和AuraBot聊天。但是不支持加入群聊。

#### 门控

用户在QQ，微信上说话不一定每次都会唤醒AuraBot，因为用户会分多条消息来说。所以需要一个门控系统来判断是否唤醒AuraBot。

#### 断句

Bot在给用户回复时，也不会是一长段。会做断句。


### 接入前端（当前已有，只需要对接口做微调）


#### Live2D渲染

- 渲染一个Live2D，会关注用户的鼠标。
- Agent会输出情绪和动作控制信号，驱动Live2D模型做表情或动作。
- 常驻屏幕，但是不让用户感觉到妨碍使用电脑。


#### 对话界面，任务界面，待提醒界面

- 一个app控制台
- 查看历史主对话记录
- 查看当前worker进程状态。
- 查看待提醒事项


#### 控制台(config panel)

- 设置模型服务商
- 设置Live2D模型
- 各种配置


### 对话交互

#### TTS+STT / Type

这里没有门控，一经发送，直接触发主Agent。

- TTS+STT
    1. 用户说话
    2. 音频捕获，STT
    3. 文字submit给主Agent
    4. 主Agent打造回复语句
    5. TTS并播放
- Type
    1. 用户直接在对话框里打字
    2. 文字submit给主Agent
    3. 主Agent打造回复语句

#### SOUL

Bot说话时，有自己的SOUL，会对语气做模仿。
