# 聊天Agent

聊天模块会载入SOUL的profile信息，以及只载入基础的Skill。

聊天Agent持有memory库，有对库的写入和检索权限。


聊天Agent的会话上下文是“栈”结构。
- 从头到尾只有一个session！所以用户对于整个项目都不需要做session的切换和管理。
- 加载入上下文是栈结构的文本
    - 需要执行子任务，把子任务上下文压入
    - 子任务结束，上下文弹走，上下文窗口里只保留子任务结果。
- 单次对话触发（脉冲）生命周期中，会做的事
    - 查记忆库
    - 查skill库
    - 查tool库
    * tool,skill库中保有的内容是用于指派给子agent，一开始不会加载入自己的上下文。
    - 查子进程列表以及当前状态。

对话上下文 ≠ AuraBot会对用户说的话。
我们通过以下方法的一种决定对用户说哪些话
- post to user工具调用。
- LLM返回字段“post”解析给用户。
