## 功能

### Live2D演出

导入Live2D模型后，AuraBot会解析这个模型附带的动作和表情。

你可以预览并配置这些表情来让Bot真情演出。

### 语音聊天

我们实现了非常流畅的语音聊天功能。

语音聊天有2种架构

- **流水线模式(Pipeline)**：可自主配置内部对话的大语言模型，扩展性强、回复快速并且很聪明。
- **实时语音模式(Realtime)**：使用全双工的多模态模型，回复更流畅，也更真实。

### 角色扮演与长期记忆

AuraBot会逐步了解你。

你可以给你的助理主动配置人设描述。

在对话中，你的助理也会自动记住你的爱好、性格，变得更加默契。

### 完成工作

AuraBot内置工作系统。

你可以在对话中直接描述任务，AuraBot会在后台自动推进任务。并在任务完成后汇报。

你也可以主动监督任务进度，并直接要求bot修改或中止任务。
## 安装与配置

### 安装

你可以去发行页下载安装包，也可以直接[从源码安装](./notes/source-installation.md)。

> 对于Mac，首次运行可能被操作系统阻挡。可以去设置->隐私与安全性->翻到底部选择“仍要运行”来手动授权。

### 配置

> AuraBot的配置有些复杂哦，可能需要花十几分钟完成整个功能的配置，请耐心读完。

#### 1. 主控按键

把鼠标移动到桌宠上方，可以看到右侧出现三个按钮：

- 上方按钮点击后弹出对话记录窗口
- 中间的按钮用于控制语音聊天的开启和关闭状态
- 下方的按钮用于拖拽平移桌宠位置
- 最右下方的绿色勾角用于拖拽改变桌宠窗口形状

**初次配置，请点击上方按钮进入对话记录。**

#### 2. 对话记录页

这里可以在下方手动输入文字来和Bot发消息。

左上角的按钮可以点击弹出或收缩任务列表。AuraBot正在推进的所有任务都会显示在这里。

点击右上角的齿轮可以进入详细设置。

**首次配置，请进入设置页。**

#### 3. 任务模型和搜索接口

你可以在”能力集成“页配置用于执行任务的模型。只需输入一个OpenAI兼容API(包含base_url, api_key, model_name)。

有时候bot需要搜索外部信息才能准确回答你的问题或完成任务。配置一个[Tavily API Key](https://www.tavily.com/)即可。

> *Tavily免费账户每个月可用1000次搜索，完全够用*

#### 4. 配置工作区

AuraBot在指派任务时，需要知道自己可以从哪些初始工作目录开始。

比如你添加工作区"桌面"，设置目录绝对路径`~/Desktop/`。之后你在对话中说“帮我在桌面上......”，bot就知道需要在桌面上完成工作。

#### 5. Profiles

一份profile其实就是一份角色档案。

在角色配置页可以查看和管理所有profiles。

每个profile都有自己的名称、人设、记忆库、Live2D展示与动作配置和语音对话模式与声线配置。

点击“编辑”，进入角色详情页。

#### 6. Profile-角色

在角色页编辑profile的名称和人设。

SOUL其实就是详细的人设描述。你可以在这里介绍这个虚拟人格的来历、存在形式、性格、爱好、特长和对用户的态度。这分SOUL会被送进系统提示词。

#### 7. Profile-模型与动作

1. 点击右边上方“导入模型文件夹”，可以为profile替换Live2D模型。
2. 左下角“显示完整模型”表示窗口是否强制展示完整模型。如果不勾选，如果窗口较宽，会只展示模型的上半身。
3. 左下角“查看方向灵敏度”表示模型看向鼠标指针的幅度。这个选项存在的意义是不同模型看向鼠标指针的基准动作幅度不一样。通过手动校准，可以获得自然的看板动作。
4. 左下角“说话口型灵敏度”表示bot说话时，嘴巴开合程度。同上，不同的模型说话时，嘴巴开合的基线幅度不一样。通过手动校准，获得自然的说话腔调。
5. 右侧“动作”和“表情”栏都是解析到的Live2D模型附带的动作和表情。

   点击一个条目会在左侧展示动作或表情的预览。有些模型默认不给动作和表情命名，你可以通过预览主动给动作或表情命名或改名。

   在下方勾选“允许角色在对话中使用”则表示这个表情会注入模型上下文。Bot在对话中，会主动演绎这些表情。

6. 右侧“常驻”表示模型在默认状态下展示的动作或表情。

   默认状态分4种

   - 待机
   - 聆听
   - 说话
   - 思考

   你可以分别配置Bot处于这些状态下，自动轮播的动作和表情。

#### 8. Profile-语音

语音服务不像LLM api，有统一的接口格式(如OpenAI兼容接口)。各家的接口形式不一样。

当前版本只适配火山引擎的语音服务(后续会考虑适配更多提供商，也欢迎贡献`TwT`)。

你可以在这里选择语音处理的模式

- **Pipeline模式**：你的声音先被识别为文字(STT)，然后送入大语言模型(LLM)，最后大语言模型对你说的话会被送入语音合成模型产出可播放的声音(TTS)。别担心——这个STT-LLM-TTS流水线已经被深度优化。模型会尽快回复你，并且还能调用工具、调度子代理完成任务。
- **Realtime模式**：调用最新的实时语音模型，模型直接接收你的语音输入，并直接合成语音输出给你。这种多模态模型的回复速度往往比pipeline模式快，也更稳定。但是实时语音模型不见得有LLM聪明。

Pipeline模式下的“会话模型”就是大语言模型。这里推荐deepseek flash：响应迅速、充满智慧。

其他的模型需要去[火山引擎-豆包语音控制台](https://console.volcengine.com/speech)配置。

1. 先创建账号并登录。
2. 在豆包语音页面左下方选中“API Key”页面下创建一个API Key，然后填入语音配置页（一个API Key可以同时开通多种模型，包括语音API key和Seeduplex API Key）。
3. 在左上角选中“概览页”选择模型并点击“API接入”

    - Pipeline模式需要接入"语音合成"和"流式语音识别"
    - Realtime模式需要接入"实时语音"

4. 在左上角选中”声线库“，挑选一个声线并复制声线ID，填入语音配置页。

> 点击保存、应用。回到桌宠窗口，点击”麦克风“图标，即可开启语音对话，体验AuraBot的完整功能。

## 贡献

如果使用过程中出现问题或者有改进建议，欢迎提issue。也欢迎直接fork和pull request。

如果你想改装语音运行时，可以试试以调试模式运行：

```bash
cd frontend

npm run dev -- --debug
```

这会显示调试窗口，并产出详细的运行日志，便于分析瓶颈。
