# tts服务选择

---

## dots.tts

### 三个主要模型
1. rednote-hilab/dots.tts-base，最适合继续 fine-tune，保留完整 CFG / NFE 控制（不作应用考虑）
2. rednote-hilab/dots.tts-soar，官方推荐的默认零样本声音克隆模型，音色相似度和稳定性最好（高性能高质量对话）
3. rednote-hilab/dots.tts-mf，低延迟首选，推荐 num_steps=4，guidance_scale 对它无效

### 优点
1. 48kHz输出，音质高，细节好
2. 声音克隆能力强，可以使用参考音频做专属音色
3. 表现力好，情绪和韵律到位
4. 有多语言能力，支持中英文和多语言场景
5. 可本地部署，不依赖第三方API稳定性，隐私性也更强
6. 开源友好，可商用
7. 可微调
8.有低延迟版本，适合桌宠实时回复

### 缺点
1. 2B参数模型对GPU和显存要求高，不适合低配电脑常驻运行
2. 有延迟，生成速度和需要及时反馈的桌宠稍有出入
3. 启动慢，模型加载、warmup、首次生成都可能比较慢，影响桌宠开机体验
4. 安装包大，模型权重很大，桌宠安装包/首次下载成本高
5. 更偏 Linux/macOS/Python/PyTorch 工作流，Windows 桌宠打包会更麻烦
6. 高保真声音克隆的版权问题
7. 需要控制长文本，回复长时需要有分句、排队和打断，否则会出现等待久或播放不自然

### 综合分析
dots.tts本地模型对GPU和显存有一定要求，但生成质量比较高且可以克隆音色，适合需要高质量回复且有GPU、愿意接受模型权重下载的用户
