# AuraBot 概念

## 是什么

AuraBot 是一个运行在桌面端的 AI 伴侣。它的第一优先级是**高活人感的聊天陪伴**，同时具备任务代理与轻量助手能力。

## 核心概念

### Soul
每个 Profile 的人格底稿，定义表达风格、关系定位、话题偏好和互动边界。

### 记忆系统
采用**分层摘要 + 图状联想**的混合结构。分两类：
- **时间驱动记忆**：与事件、时间节点绑定，支持追问与关怀（如"你说下周有演唱会，怎么样？"）
- **非时间驱动记忆**：稳定偏好与长期印象（如"喜欢火锅、讨厌跑步"）

记忆支持联想型召回，而不只是关键词匹配。

### 对话触发系统
判断"该不该开口、什么时候开口"。

触发逻辑依赖轻量判断单元，识别用户是否说完、当前是否应该回复。
因此，用户连续发多条短消息时，AuraBot 会等待完整语义段落形成后再回。

系统实时判断用户输入属于聊天还是任务委派，分走完全不同的处理路径。

### 线程结构
**单主聊天线程 + 若干任务子线程**。主线程全局唯一，承载长期关系与记忆；任务在独立子线程执行，结果回流主线程。主线程对子线程有查询、打断、修改权限。

因此，我们需要一种机制来让主聊天session无限长。

### Profiles

同一设备上可维护多个独立的人格体，各自拥有独立的 Soul、记忆库和session库。
