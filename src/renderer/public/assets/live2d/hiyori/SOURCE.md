# Hiyori Live2D Model Source

- Source repository: https://github.com/Live2D/CubismWebSamples
- Source folder: `Samples/Resources/Hiyori`
- Live2D sample page: https://www.live2d.com/en/learn/sample/
- Model manifest: `Hiyori.model3.json`
- License reference: https://github.com/Live2D/CubismWebSamples/blob/develop/LICENSE.md

The model files in this folder were downloaded from Live2D's official Cubism Web Samples repository for the AuraBot prototype. The upstream license lists Hiyori under Live2D's Free Material License, and Live2D's sample page identifies Hiyori Momose as a free sample model for avatars, game apps, and Cubism SDK use.
